# SOLID Principles:

---

### SRP (Single responsibility principle):

A service/class should only have 1 reason to change.

---

### OCP (Open for extension/Closed for modification principle):

A module should be extendable for extra functionality with no modifications in the module itself.

---

### LSP (Liskov's Substitution principle):

A subclass replacing a base class should never break the program, so that object behavior is predictable.

---

### ISP (Interface segregation principle):

A class implementing an interface should never need to leave a function empty or unimplemented. (Prevent fat interfaces)

---

### DIP (Dependancy inversion principle):

Both high-level and low-level modules should depend on abstractions, not on each other directly
